## 1. Blocking before the next race

### 1.1 `hud_wear_enabled` is still `False`
The live tyre-wear gauge — `pitcrew/telemetry/hud.py`, reading GT7's HUD off OBS
to 0.5% — is built, tested and wired, and **switched off**. Nothing that depends
on wear works until it is on:

* `intents.TYRES` answers *"No tyre gauge — read it to me."* to every
  "how are my tyres" (`controller.py:3554`, snapshot key `wearWorst`).
* The colour tier's wear line never fires (`race/colour.py:226`).
* `brief()` declares *"No tyre gauge this race"* on the grid.

Turning it on needs OBS running with the websocket enabled, and it has **never
been exercised during a live race** — only against a recorded video. It needs a
practice session end-to-end before it is trusted on race night.

**There is no settings UI for it.** `hud_wear_enabled`, `obs_host`, `obs_port`,
`obs_password` exist in `settings.py` and appear nowhere in
`ui/settings_screen.py`. Either add the controls or set it in the config file.

### 1.2 `ptt_toggle` has no settings UI either
Tap-to-talk is the default and there is no way to switch back to hold-to-talk
except by editing the config. Add it next to the existing push-to-talk controls.

### 1.3 The radio static is unheard at the rig
Both bursts render and play — that is all that has been verified. Level and
length are one number each in `pitcrew/engineer/radio.py`: `LEVEL = 0.22`,
`BURST_MS = 130`. Listen through the actual headset and adjust.

### 1.4 Events still carry the wrong game version
GT7 is on **1.71** since 20 Aug — a physics update that rewrote the tyre slip
model, per-car steering geometry, damper attenuation, and suspension/diff/aero
defaults *and ranges*.

    event 1  Round 8 Porsche Cup   game_version = None
    event 2  Round 3 Supercars     game_version = '1.70'
    event 3  Round 3 GR3           game_version = '1.70'

Every stored wear number, slider range and threshold behind these is pre-patch.
`settings.game_version` is now `''` rather than a stale default, so **new**
sessions no longer inherit a wrong version — but nothing has restamped the
events, and the export refuses an event that straddles two versions.

## 4. Measurements worth not repeating

Written down so the next session does not re-derive them.

* **SAPI has never once started on this machine** — 59 attempts, 59 hangs, ten
  days. It blocks rather than raising. Do not put it first in any chain.
* **Moonshine comes up in 2.3–2.7 s** measured alone, every time.
* **The PTT gate has no separable gap** between real questions (0.066–0.505) and
  unrelated speech (0.170–0.573), and no margin rule creates one. Distance
  barely predicts correctness: **82% right below 0.34, 80% above.** The bands
  are set on cost-of-being-wrong, not on separation. Re-measure only if the
  phrase list or the embedding model changes.
* **The mic is fine** — 167 ms to first audio block. `0.00s captured` in the log
  is the disconnected-Bluetooth-default-input case, which already has its own
  spoken message.
* **Lateral load is what makes a straight findable**, not throttle. `v * yaw`,
  the same quantity `telemetry/recorder` derives `lat_g` from.
