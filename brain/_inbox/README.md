# `_inbox` — raw exports from the "My Driving Style - Tuning" Project

Drop the Project's knowledge files here, unedited and under their original
names. **Nothing in this folder is authoritative.** It is the raw import, kept
exactly as exported so that every later decision can be traced back to what the
Project actually said rather than to what somebody remembered it saying.

Triage turns these into `brain/` proper — a small always-loaded core, an
on-demand reference tier, and an archive of what has been superseded. The
archive keeps superseded material **visible with its supersession recorded**,
never deleted: a rule that was believed and then disproved is itself evidence,
and silently dropping it invites re-adopting it a season later.

The numbered files are doctrine. The dated, car-and-circuit files are event
outputs and belong with the sheets they produced.
